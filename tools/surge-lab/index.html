Per-part supply allocation is simulated in drive order. Actual KSP resource graph, crossfeed and callback order are unknown; the shared-bus mode is a design proposal.
SURGE Lab cannot demonstrate that the reported ~30 g ceiling is fixed. No gravity, atmospheric forces, rotation dynamics, KSP resource routing or patched-conic orbits are simulated. Target-relative guidance uses straight-line constant-acceleration estimates and can miss a moving target.
Equations: requested EC/s = a × throttle per drive; applied acceleration = a × throttle × clamp(EC delivered / EC requested, 0, 1) along each oriented drive axis. World velocity integrates summed acceleration using a fixed 0.1 s step. GitHub fork · Upstream
